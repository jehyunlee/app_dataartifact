Claude API 키 설정

키는 이 브라우저에만 두고 Anthropic API(api.anthropic.com)로만 보냅니다. 설정 파일은 브라우저가 경로로 직접 열 수 없어 파일 선택 창으로 고릅니다. ANTHROPIC_API_KEY=… 줄이 있는 .env, {"ANTHROPIC_API_KEY": "…"} 형태의 JSON, 또는 키 한 줄짜리 파일을 읽습니다. ‘기억’을 끄면 탭을 닫을 때 지워집니다.
